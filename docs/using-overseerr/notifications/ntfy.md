# ntfy

## Configuration

### Server URL

Set this to the URL of your ntfy server. It defaults to `https://ntfy.sh`, the
publicly-hosted instance.

### Topic

Set this topic to whatever you like. This is where all messages will be
published to.

{% hint style="info" %}
Please refer to the [ntfy API documentation](https://docs.ntfy.sh/) for more
details on the service
{% endhint %}
